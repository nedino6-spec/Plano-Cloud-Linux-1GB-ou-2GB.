# Sistema de Gestão para Barbearia 2026

Aplicativo desktop em Python/Tkinter para controlar uma barbearia com:

- Cadastro de clientes, barbeiros e serviços.
- Agenda por horário com geração de link/mensagem para WhatsApp.
- Fila de atendimento por ordem de chegada.
- Painel administrativo com resumo de faturamento, agenda e fila.
- Banco SQLite local (`barbearia.db`).

## Como executar

```bash
python3 barbearia_app.py
```

O sistema usa apenas bibliotecas padrão do Python.
